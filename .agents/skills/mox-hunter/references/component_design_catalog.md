# 📐 MoX Hunter Visual Component Design Catalog
*(5 Headers • 5 Heroes • 5 Forms/CTAs • 5 Footers)*

This catalog provides structural blueprints and HTML/Tailwind specifications for each essential UI component, ensuring zero repetition across client campaigns.

---

## 🧭 I. The 5 Distinct Header & Navigation Designs

### 1. Header Type A: Floating Glassmorphism Island
* **Style**: Detached rounded-full capsule floating 24px below viewport top.
* **Colors**: `backdrop-blur-xl bg-slate-950/80 border border-slate-700/50 shadow-2xl`
* **Layout**: [Logo + Live Status Dot] ── [Centered Navigation Links] ── [Phone + Pill CTA Button]
* **Best For**: High-end clinical aesthetics (Care N Cure, Hissam & Associates).

### 2. Header Type B: Dual-Tier British Royal Bar
* **Style**: Full-width dual bar. Top row provides trust metrics; bottom row provides main navigation.
* **Tier 1 (Top)**: Royal Oxford Blue `#0b1426` with British Flag badge 🇬🇧, working hours, and telephone.
* **Tier 2 (Bottom)**: Sticky `#070d18` with large brand logo, specialist badges, and consultation CTA.
* **Best For**: Legacy practices, overseas credentials (Kensington Dental).

### 3. Header Type C: Asymmetric Monogram & Direct Line
* **Style**: Minimalist architectural navbar with oversized stylized monogram on left.
* **Colors**: Obsidian `#050a14` with Champagne Gold trim `#d4af37`.
* **Layout**: Left: Monogram (`HA`) + Practice Name | Right: WhatsApp direct chat button + Call icon.
* **Best For**: Diplomatic & VIP aesthetic suites (Beverly Centre, Blue Area).

### 4. Header Type D: Medical Specialist Ribbon
* **Style**: Clean clinical emerald/titanium navbar with physical location badge.
* **Layout**: Top ribbon: "📍 Office 8, Block 12-C, Jinnah Super Market" | Bottom: Specialist matrix tabs.
* **Best For**: Multi-disciplinary dental groups (The Dental Consultants).

### 5. Header Type E: 24/7 Flashing Emergency Action Bar
* **Style**: High-contrast urgent alert banner with pulsing red indicator dot.
* **Banner**: *"🚨 24/7 Emergency Dental Surgery in F-7 Markaz • Call 0333-5556789"*
* **Bottom Nav**: High-tech cobalt blue with 1-click "Same-Day Relief" button.
* **Best For**: Urgent care, surgical trauma, acute pain triage (Smile Square).
