# MoX Hunter Dynamic Section Hierarchy & Layout Rhythm Engine

To eliminate "generic AI template" and "twin layout" syndrome, every prototype built by `mox-ui-designer` must enforce **Layout Rhythm Variation**. No two consecutive sections may use the same structural pattern (e.g., never two 3-column card grids back-to-back).

---

## 🎨 Layout Rhythm Rules:
1. **Rule of Alternating Density**: A dense content section (Bento Grid) must always be followed by an open, breathable visual section (High-Contrast Banner or Interactive Widget).
2. **Asymmetric Visual Weight**: Avoid rigid symmetric 3-card rows. Use span-2 / span-1 bento boxes with varying aspect ratios.
3. **Micro-Interactions**: Use smooth CSS hover zooms, active tab states, and real-time JavaScript calculators to give the feel of a $10,000 custom web agency build.
4. **Color Rhythm**: Alternating soft pearl/alabaster with clean white cards and deep brand accent anchors.
